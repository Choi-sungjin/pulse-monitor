원본 수치는 실행 중인 센서 값이다. 임의 값으로 대체하지 않았다.
사용 안내는 실제 화면의 발췌 구간을 반복하며 숫자 확인, 상세 열기 단축키,
설정·추가 센서 버튼 위치, 닫는 방법을 순서대로 설명한다.
설정 메뉴를 직접 클릭하는 과정을 연속 촬영한 영상은 아니다.

촬영은 사용자 요청에 따라 한 번 진행했고, 앱에 자동 녹화 기능을 추가하지 않았다.
배포용 미디어에는 위젯 영역만 넣었다. 다른 앱 화면, 경로, 계정 정보가 있는 원본 전체 화면은 포함하지 않는다.
상세 창의 둥근 모서리 바깥쪽은 안내 배경으로 가려 관련 없는 창 테두리를 제외했다.

FFmpeg로 실제 화면을 제한된 영역만 녹화하고 GIF를 생성했다.
ffprobe로 두 GIF의 크기·길이·프레임 수를 확인했고, 대표 단계 이미지를 육안 검토했다.
두 GIF 모두 반복 재생하도록 설정했다. README의 상대 이미지 경로와 UTF-8 인코딩도 확인했다.
GitHub 웹사이트에서의 실제 렌더링은 아직 게시 전이므로 미검증이다.
